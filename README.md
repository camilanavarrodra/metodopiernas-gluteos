# Funil en español · Piernas y Glúteos

## Archivos
- `index.html` → quiz
- `oferta.html` → página de ventas
- `styles.css` → estilos
- `quiz.js` → lógica del quiz
- `oferta.js` → lógica de la oferta
- `config.js` → configuración del precio y del checkout
- `assets/` → imágenes de referencia usadas

## Activar Cakto
En `config.js`, cambia:
```js
checkoutUrl:''
```
por tu URL real del checkout.

## Cambiar precio
Edita en `config.js`:
- `productPrice`
- `oldPrice`
- `priceCaption`

## Nota
Esta versión está más agresiva visualmente y más enfocada en conversión, usando los elementos compartidos: urgencia, bloque de precio, headline, testimonios, antes/después y garantía.
